# TrendHunter Database Schema (v3.5)

## Overview
- **Database File:** `TrendHunter/db/stock_info.db`
- **Engine:** SQLite3
- **Purpose:** Stores market data, fundamental info, technical indicators, and trade plans.

---

## Tables

### 1. `master_info`
*   **Description:** Comprehensive stock metadata and fundamental financial ratios.
*   **Source:** KIS API Master Data (`mst` files) and Fundamental API.
*   **Update Frequency:** Monthly for master data, Quarterly for financial data.

| Category | Column | Type | Description |
| :--- | :--- | :--- | :--- |
| **Identity** | `code` | TEXT | Stock Symbol (PK) |
| | `name` | TEXT | Stock Name |
| | `market_type` | TEXT | KOSPI / KOSDAQ |
| **Classification** | `bstp_larg_div_code` | TEXT | Industry Large Category |
| | `bstp_medm_div_code` | TEXT | Industry Medium Category |
| | `bstp_smal_div_code` | TEXT | Industry Small Category |
| **Fundamentals** | `bsop_prfi` | INTEGER | Operating Profit (영업이익) |
| | `thtr_ntin` | INTEGER | Net Income (당기순이익) |
| | `roe` | REAL | Return on Equity |
| | `stck_fcam` | INTEGER | Par Value (액면가) |
| | `lstn_stcn` | INTEGER | Listed Shares |
| | `cpfn` | INTEGER | Capital |
| **Dividends** | `per_stock_dvdn_amt` | INTEGER | Dividend Per Share (DPS) |
| | `dividend_cycle` | TEXT | Dividend Frequency (Monthly/Quarterly/Annual) |
| | `dividend_count` | INTEGER | Annual Dividend Payout Count |
| **Flags** | `trht_yn`, `mang_issu_yn` | TEXT | Trade Halt / Managed Stock Flags |
| | `crdt_able` | TEXT | Credit Order Availability |
| | `updated_at` | TEXT | Last Sync Timestamp |

### 2. `daily_analysis`
*   **Description:** Daily price history, technical indicators, supply/demand, and growth metrics.
*   **Source:** KIS API Daily Charts & Investor Supply API.

| Category | Column | Type | Description |
| :--- | :--- | :--- | :--- |
| **PK** | `date`, `code` | TEXT | Composite Primary Key (YYYYMMDD) |
| **Market Data** | `open`, `high`, `low`, `close` | INTEGER | OHLC Prices |
| | `volume`, `amount` | INTEGER | Volume and Trading Value (Won) |
| | `market_cap` | INTEGER | Daily Market Capitalization |
| **Technical** | `sma_20`, `50`, `150`, `200` | REAL | Simple Moving Averages |
| | `volume_sma_50` | REAL | 50-Day Volume SMA |
| | `high_52w`, `low_52w` | INTEGER | 52-Week High/Low (Intraday) |
| | `rs_score` | REAL | Relative Strength Score (0-99) |
| | `vol_std_10d`, `50d` | REAL | 10-Day and 50-Day Volatility (Std Dev) |
| **Growth/Div** | `dividend_yield` | REAL | Dynamic Yield (%) |
| | `revenue_growth` | REAL | Revenue Growth Rate (%) |
| | `eps_growth` | REAL | EPS Growth Rate (%) |
| | `operating_margin` | REAL | Operating Profit Margin (%) |
| **Supply** | `frgn_net_buy` | INTEGER | Foreigner Net Buy |
| | `orgn_net_buy` | INTEGER | Institution Net Buy |
| | `pension_net_buy` | INTEGER | Pension Fund Net Buy |
| | `prsn_net_buy` | INTEGER | Personal Net Buy |
| | `inv_net_buy`, `fin_net_buy` | INTEGER | Trust / Financial Inv. Net Buy |

### 3. `trade_plan`
*   **Description:** Actionable trade candidates generated by the screener.

| Column | Type | Description |
| :--- | :--- | :--- |
| `id` | INTEGER | PK (Auto-increment) |
| `date` | TEXT | Plan Creation Date (YYYY-MM-DD) |
| `code`, `name` | TEXT | Stock Identification |
| `entry_price` | INTEGER | Target Breakout Price (Pivot) |
| `stop_price` | INTEGER | Survival Stop-Loss Price |
| `weight` | TEXT | Portfolio Allocation (e.g., "15%") |
| `track` | TEXT | Strategy Origin (e.g., Track 1, Track 2) |
| `rs_score` | REAL | RS Score at time of planning |
| `vcp_ratio` | REAL | VCP Ratio at time of planning |
| `rationale` | TEXT | Reason for selection |
| `status` | TEXT | `READY`, `BOUGHT`, `SOLD`, `CANCEL` |

---

## Views

### `view_trend_candidates`
Calculates `vcp_ratio` and filters for basic Trend Template alignment.

### `view_dividend_candidates`
Filters for high-yield stocks (>5%) and joins with DPS metadata.
