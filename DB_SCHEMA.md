# TrendHunter Database Schema (v5.4)

## Overview
- **Database File:** `TrendHunter/db/stock_info.db`
- **Engine:** SQLite3
- **Purpose:** Stores market data, fundamental info, technical indicators, and trade plans.

---

## Tables

### 1. `master_info`
*   **Source:** KIS API Master Data (`mst` files) and Fundamental API.

| Category | Column | Type | Description |
| :--- | :--- | :--- | :--- |
| **Identity** | `code`, `name`, `market_type` | TEXT | Stock Identification |
| **Fundamentals** | `bsop_prfi`, `thtr_ntin` | INTEGER | Operating Profit, Net Income (KRW 1M) |
| | `roe` | REAL | Return on Equity (%) |
| **Dividends** | `per_stock_dvdn_amt` | INTEGER | Dividend Per Share (DPS) |
| | `dividend_cycle`, `count` | TEXT | Payout Frequency & Annual Count |

### 2. `daily_analysis`
*   **Source:** KIS API Daily Charts (Adjusted Price) & Investor Supply API.

| Category | Column | Type | Description |
| :--- | :--- | :--- | :--- |
| **PK** | `date`, `code` | TEXT | YYYYMMDD |
| **Market Data** | `open`, `high`, `low`, `close` | INTEGER | **Adjusted Price (`adj_prc: 0`)** |
| | `volume`, `amount` | INTEGER | Volume and Trading Value (KRW) |
| **Technical** | `sma_20`, `50`, `150`, `200` | REAL | Trend Template Alignment |
| | `volume_sma_50` | REAL | **VDU Filter** Basis |

| | `rs_score` | REAL | Relative Strength (3/6/9/12m Weighted) |

### 3. `trade_plan`
*   **Description:** Actionable trade candidates generated by the screener.

| Column | Type | Description |
| :--- | :--- | :--- |
| `entry_price` | INTEGER | **Round-Figure Adjusted** Pivot Price |
| `stop_price` | INTEGER | Strategic Stop-Loss |
| `status` | TEXT | `READY`, `WATCH`, `CANCEL` |
| `rationale` | TEXT | RS / VCP Score Context |

### 4. `market_summary` (New)
*   **Description:** Aggregated market health data.

| Column | Type | Description |
| :--- | :--- | :--- |

## Data Collection Pipeline Rules

1.  **Adjusted Price**: All price data must be adjusted to prevent chart gaps during dividends/rights issues.
2.  **Units**: Financial values are stored in **Millions (1,000,000)**. Shares are in **Units (1)**.
3.  **Mining Engine (v3.6)**: Dividend yields are recalculated daily based on the latest `close` and stored `per_stock_dvdn_amt`.
4.  **VCP Tightness**: Tightness score is defined as `(High - Low) / Close`. The screener filters for average tightness < 4% (Strict) or 6% (Relaxed) over the last 5 days.
