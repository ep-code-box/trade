# Project Context: TrendHunter

## 1. Project Overview
**TrendHunter** is a sophisticated quantitative trading system engineered for the **Korea Investment & Securities (KIS)** API. It automates the investment process by rigorously applying the strategies of market legends—**Jesse Livermore** (Price Action), **William O'Neil** (CANSLIM), and **Mark Minervini** (Volatility Contraction Pattern).

The system is designed to eliminate emotional bias, strictly adhering to mechanical rules for entry, position sizing, and risk management. It consists of a robust **Python Backend Analysis Engine** and a modern **React-based Web Dashboard** for visualization.

## 2. Core Architecture
The system follows a modular, service-oriented architecture:

### A. Central Control & Backend (`src/`)
-   **`run.py`**: The unified CLI entry point. It orchestrates all tasks including data ingestion, analysis, and reporting.
-   **`api.py` (FastAPI)**: A lightweight REST API server that powers the frontend dashboard by serving real-time market data and analysis results.
-   **`jobs/`**: Dedicated modules for data collection pipelines. It handles KIS API rate limiting (30 TPS), error retries, and maintenance windows.
-   **`analysis/`**: The quantitative core. It implements algorithms for RS Score calculation, VCP pattern detection, and supply/demand quality assessment.

### B. Frontend Dashboard (`dashboard/`)
-   **Tech Stack**: React, Vite, TypeScript, Tailwind CSS.
-   **Purpose**: Provides a visual interface for Screening results, Interactive charting with VCP annotations, and Portfolio management.

### C. Persistence Layer (`TrendHunter/db/`)
-   **`stock_info.db` (SQLite)**: The single source of truth.
    -   **`master_info`**: Static metadata and fundamental data (PER, PBR, ROE, Dividends).
    -   **`daily_analysis`**: Time-series OHLCV data, calculated technical indicators, and investor supply logs.
    -   **`trade_plan`**: Automated trading plans (Entry, Stop-loss, Weight) generated by the screener.
    -   **`market_summary`**: Daily market thermometer data (Stage 2 ratio, Top sectors).

## 3. Investment Strategy: The 3-Track System

### TRACK 1: Trend Following (Aggressive Growth)
*   **Philosophy**: "Buy high, sell higher." Target market leaders in strong uptrends.
*   **Selection Criteria (Master's Edge v5.4)**:
    1.  **Strict Trend**: Price > SMA(20) > SMA(50) > SMA(150) > SMA(200).
    2.  **Trend Slope**: SMA(200) current > SMA(200) 1-month ago (상승 기울기 필수).
    3.  **Relative Strength**: RS Score ≥ 80 (Market Leaders).
    4.  **Dynamic VCP (Tightness)**: 
        -   **Strict**: 5-day Avg Range < 4%.
        -   **Relaxed**: 5-day Avg Range < 6% (If no strict candidates).
        -   **Trend**: Tightness must be contracting (Recent < Previous * 1.1).
    5.  **Volume Dry-up (VDU)**: Current Volume < 50-day Volume SMA * 0.8.

### TRACK EX: Independent Momentum (Catalyst Driven)
*   **Criteria**: Meets Track 1 technical criteria but belongs to niche sectors or independent catalysts.
*   **Supply Intel**: Priority given to **Double-Buy (💎 쌍끌이)** stocks.

### TRACK 2: Toobuk Investment (Dividend & Stability)
*   **Criteria**: Yield ≥ 7.0%, ROE ≥ 10.0%, Positive Net Income.

## 4. Data Collection Pipeline (Operational Workflow)

The system operates on a rigorous 8-step pipeline, ensuring data integrity at each stage:

1.  **Identity Sync (`sync`)**: Synchronizes KOSPI/KOSDAQ masters from MST files.
2.  **Context Mapping (`themes`)**: Maps stocks to sectors/themes to identify "Theme Clusters."
3.  **Market Thermometer (`daily`)**: Fetches Index (0001, 1001) and Stock price trends using **Adjusted Price (`adj_prc: 0`)**.
4.  **Financial Audit (`fundamentals`)**: Collects ROE, Operating Profit, and Net Income.
5.  **Dividend Mining (`mine`)**: v3.6 Mining engine calculates real-time dividend yields based on current price and TTM DPS.
6.  **Supply Intel (`supply`)**: Audits institutional and foreign accumulation. Identifies **Double-Buy (💎)** signals.
7.  **Momentum Ranking (`rs`)**: Percentile ranks all 3,800+ stocks using multi-period (3/6/9/12m) weighted RS Score.
8.  **Screener Execution (`screen`)**: 
    -   Performs **Sector Dominance Analysis** (identifies top sectors regardless of VCP).
    -   Applies **Dynamic VCP Filter** to find precise entry points.
    -   Calculates **Round-Figure Adjusted Entry Prices** (Psychological resistance bypass).

## 5. Technical Implementation Details

- **Adjusted Price Accuracy**: "A chart without adjustment is a lie." All calculations use `adj_prc: 0`.
- **Accumulation Evidence**: `up_supply > down_supply * 1.5` identifies aggressive institutional accumulation.
- **Tightness Trend**: VCP is not just a ratio; it must show a **downward trend in daily price ranges** over the last 10 days.
- **30 TPS Engine**: Uses asynchronous I/O to maximize KIS API throughput while strictly honoring rate limits.

## 6. 개발 및 운영 절대 원칙 (The Master's Core)

### A. 데이터 무결성 지침 (Data Integrity)
- **명세서 준수**: 재무제표(백만 원), 상장주수(주), 배당성향(%) 단위를 절대 준수한다.
- **ROE 파싱**: 자의적인 캡핑 없이 공식 API 수치를 정직하게 파싱한다.

### B. 퀀트 필터 지침 (Master's Filter)
- **Strict 2단계 상승장**: `SMA(150) > SMA(200)` and `SMA(200) Slope > 0`.
- **VCP 수축**: 4% 이내(Strict) 조준을 원칙으로 하되, 없을 경우 6% 이내(Relaxed) 차선책을 검토한다.
- **Stop-Loss**: ATR 변동성 혹은 주요 이평선 이탈 시 기계적으로 매도(CANCEL)한다.
